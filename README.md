# 🖥️ Lite Code Box

> Write. Preview. Learn. — All in one file.

**Lite Code Box** is a portable, zero-setup code editor built for teaching and learning web development.  
It lets you write **HTML, CSS, and JavaScript** with **real-time preview**, validation, and save/load features — all inside a single file.

No installations. No servers. No logins.  
Just open and start coding ✨.
